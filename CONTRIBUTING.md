# Contributing to BroTube

Thank you for your interest in contributing to **BroTube**! We welcome bug fixes, improvements, and feature contributions from the community.

## Code of Conduct

Please maintain a respectful, constructive, and welcoming environment for everyone.

## Development Workflow

1. **Fork the Repository**:
   Click the **Fork** button at the top right of the [BroTube Repository](https://github.com/SatyamPandey001/BroTube).

2. **Clone Your Fork**:
   ```bash
   git clone https://github.com/<your-username>/BroTube.git
   cd BroTube
   ```

3. **Install Dependencies**:
   ```bash
   npm install
   ```

4. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```

5. **Run Self-Checks**:
   Before submitting code, ensure all diagnostic tests pass:
   ```bash
   npm test
   ```

6. **Commit & Push**:
   ```bash
   git commit -m "feat: describe your change clearly"
   git push origin feature/my-new-feature
   ```

7. **Submit a Pull Request**:
   Open a PR against the `main` branch with a clear description of the problem solved and test results.

## Reporting Issues

If you encounter bugs, broken YouTube layouts, or have feature suggestions:
- Check existing [GitHub Issues](https://github.com/SatyamPandey001/BroTube/issues) before opening a new one.
- Provide your OS version, Node.js version, and relevant logs from the **Debug Mode** scanner in BroTube's Settings menu.
